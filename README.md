# AuthSystem

## Sobre o projeto

O **AuthSystem** é um projeto full stack desenvolvido com o objetivo de implementar um sistema completo de autenticação de usuários, utilizando JavaScript e diferentes tecnologias do desenvolvimento web.

A aplicação contará com interfaces simples de **login e cadastro**, priorizando o funcionamento da autenticação, a integração entre front-end e back-end, o gerenciamento de sessões, a segurança e a persistência de dados em banco de dados.

O projeto tem caráter educacional e profissional, buscando aplicar na prática tecnologias, ferramentas e conceitos frequentemente exigidos em vagas de estágio na área de desenvolvimento de software.

## Objetivos de aprendizado

O principal objetivo do AuthSystem é **desenvolver competências técnicas alinhadas aos requisitos de vagas de estágio em desenvolvimento de software**, utilizando um projeto prático para estudar e comprovar conhecimentos.

Entre os objetivos estão:

- Aprender e aplicar tecnologias utilizadas no desenvolvimento web profissional.
- Compreender a comunicação entre front-end, back-end e banco de dados.
- Desenvolver conhecimentos em APIs, autenticação e segurança.
- Praticar organização de código, versionamento e manutenção de software.
- Conhecer ferramentas de testes, automação e infraestrutura.
- Construir experiência prática com tecnologias presentes nos requisitos de processos seletivos.
